## 🚨 Troubleshooting

### If build fails after pushing to Vercel:
1. Check Vercel logs in dashboard
2. Verify build command: `npm run build`
3. Check for environment variables needed
4. Run `npm run build` locally to test
5. Check Node.js version compatibility

### If pages don't load:
1. Check deployment status in Vercel
2. Check Network tab (F12) for 404 errors
3. Verify image paths are correct
4. Clear browser cache
5. Check Vercel error logs

### If metadata not showing in social sharing:
1. Use https://www.opengraph.xyz/ to check
2. Clear social platform cache
3. Re-submit URL to platforms
4. Wait 24-48 hours for indexing
